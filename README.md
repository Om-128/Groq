# 🌐 Language Translator AI

A simple **Language Translator AI** built using **Groq LPU Inference**, the **GPT-OSS-20B model**, and **LangChain**.  
It uses **PromptTemplate**, **StringParser**, and **LangServe** to provide a fast translation API.

- LangServe API endpoint
